# Training Services – Sales Analytics Dashboard | Power BI

## Project Overview

This project is an interactive Sales Analytics Dashboard developed using Microsoft Power BI to analyze training services sales data.

The dashboard provides insights into monthly sales trends, regional sales performance, order status distribution, and detailed order-level information.

It helps users understand sales patterns, compare regional performance, and monitor order distribution through interactive visualizations.

## Dashboard Features

### 1. Monthly Sales by Region
- Analyze monthly sales performance.
- Compare sales across different regions.
- Identify monthly sales patterns and trends.

### 2. Total Sales by Region
- Compare total sales across regions.
- Identify regional sales contributions.
- Understand differences in regional performance.

### 3. Order Status Distribution
- Visualize the distribution of orders by status.
- Analyze order counts across different statuses.

### 4. Regional Filtering
- Interactive region slicer.
- Filter dashboard information based on selected regions.

### 5. Order Details
Detailed order-level information, including:
- Order ID
- Order Date
- Customer Name
- Region
- Course ID
- Quantity
- Unit Price
- Discount Percentage
- Order Status
